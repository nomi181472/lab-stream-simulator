# Changelog

All notable changes to the StreamLab project are documented in this file.

## [1.0.6] - 2026-11-08
- feat(osd): increase stream timestamp and camera overlay font size for enhanced legibility

## [1.0.5] - 2026-11-06
- feat: add cross-platform Linux standalone executable, Debian (.deb) package, and dual CI/CD pipeline

## [1.0.4] - 2026-11-06
- feat(ui): custom scan directory input and websocket live streaming display

## [1.0.3] - 2026-11-06
- feat(ui): display direct websocket video stream urls on camera cards and websocket console

## [1.0.2] - 2026-11-06
- Fix static frontend mounting in installer and add readiness polling for auto browser launch

## [1.0.1] - 2026-11-05
- Fixed camera streaming loop and updated UI

## [1.0.0] - 2026-11-05
- Initial enterprise virtual IP camera simulator release.
- Multi-protocol streaming: RTSP, RTMP, HLS, WebRTC, Direct MJPEG, and WebSocket.
- Profile S ONVIF Device & Media SOAP services with WS-Discovery multicast responder.
- FFmpeg persistent stream looping with dynamic real-time timestamp overlay.
- Standalone Windows installer packaging with background system tray controller.
